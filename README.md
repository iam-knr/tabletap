# Tabletap

QR-based food court ordering system prototype.

This repo currently contains:

- `docs/foodcourt-plan.md` – high-level project plan and feasibility notes.
- `prototype/` – static HTML/JS client prototype for the customer-facing flow (shop list → menus → multi-shop cart → checkout → token screen).

The goal is to support one food court with multiple shops, a single QR entry point, multi-shop cart, per-shop order tokens, and per-shop payment routing.
